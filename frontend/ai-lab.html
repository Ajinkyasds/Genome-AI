GENEVA uses Groq-powered AI for scientific interpretation. When the API is unavailable or rate-limited, the backend returns a deterministic scientific interpretation built from the exact BioPython measurements.

AI / APPLICATION LAYER

Computation first.
Interpretation second.

This architecture prevents the language model from becoming the source of exact measurements. The Python engine reads the reference sequence; GENEVA explains the structured evidence.

The local fallback keeps the exhibition demo operational when the Groq API is unavailable.
